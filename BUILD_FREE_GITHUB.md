# Free GitHub APK Build

1. Create a free GitHub account and a new repository.
2. Upload this project to the repository (or upload the ZIP and use the workflow instructions supplied with this package).
3. In GitHub, open **Actions** and run the Android build workflow.
4. When it finishes, open the workflow run and download the **MadinaTentService77F-debug-apk** artifact.

The project uses a Gradle launcher that downloads Gradle 8.13 on the GitHub runner. Gradle 8.13 is an official Gradle release.
