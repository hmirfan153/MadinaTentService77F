# مدینہ ٹینٹ سروس 77/F — Android Project V6 Final

یہ V6 فائنل پروجیکٹ ایک آف لائن، ایک فون/ایک یوزر ٹینٹ رینٹل مینجمنٹ ایپ کی بنیاد فراہم کرتا ہے۔

اہم فیچرز:
- گاہک الگ الگ محفوظ
- بکنگ اور خودکار کرایہ
- ایڈوانس اور بقایا
- بکنگ کے آئٹمز
- واپسی: واپس، گم، خراب
- اسٹاک میں کل/دستیاب/باہر/گم یا خراب کی گنتی
- روزانہ اور ماہانہ رپورٹس
- PDF رسید
- WhatsApp/Share کے ذریعے رسید شیئر
- JSON بیک اپ
- JSON Restore (موجودہ ڈیٹا کو محفوظ رکھنے والی additive restore)
- Room offline database
- اردو RTL UI

Android Studio:
1. ZIP extract کریں۔
2. Android Studio میں root folder کھولیں۔
3. Gradle Sync ہونے دیں۔
4. USB debugging والے فون یا emulator پر Run کریں۔

نوٹ: Gradle wrapper شامل نہ ہونے کی صورت میں Android Studio اپنی compatible Gradle distribution استعمال کر سکتا ہے۔
